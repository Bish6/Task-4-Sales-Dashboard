Task 4: Superstore Sales Analysis and Dashboard

## Project overview

This project completes the Data Analyst Internship Task 4 using the SuperStoreOrders dataset. Python with pandas was used to prepare the data, Power BI was used to build an interactive dashboard, and a PowerPoint presentation summarizes the work and findings.

## Work completed

1. Loaded the SuperStoreOrders CSV in Python using pandas.
2. Cleaned and prepared the data, then saved it as a CSV for Power BI.
3. Imported the prepared data into Power BI and created a calendar table and measures.
4. Built an interactive dashboard with summary cards, charts, and filters.
5. Created a PowerPoint summary of the project and dashboard.

## Dashboard contents

- KPI cards: Total Sales, Total Profit, Total Orders, Profit Margin, and Sales Growth
- Charts: Monthly Sales, Sales by Category, Profit by Category, and Sales by Region
- Filters: Year, Market, and Category

## How to view

Open the `.pbix` file in Power BI Desktop. Use the Year, Market, and Category filters to explore the dashboard. Open the `.pptx` file in PowerPoint to see the project summary and dashboard findings.


Sales Growth is a comparison measure. Select a single year in the Year filter when interpreting it as growth against the previous year. With all years selected, it should not be described as the growth for one particular year.
